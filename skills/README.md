# Skills servidas por MCP

ZanaLLaima sirve estas skills con `zana_skill_list` y `zana_skill_load(name)`. Son instrucciones para el anfitrión, no capacidades: no autorizan escrituras ni sustituyen los gates del servidor.

Procedencia de los lentes `review-*` y `review-discipline`: adaptados al español desde los agentes `review-*` de [Gentleman-Programming/gentle-shell](https://github.com/Gentleman-Programming/gentle-shell) en el commit `3210886c79360a9f47ac3ca0cd2c1edf43b2432e` (licencia MIT, Copyright (c) 2025 Mario Zechner), tal como los vendoriza `riquelmechile/panter-ai@1a99048` en `vendor/gentle-shell/assets/agents/`.
